# Airsol HVAC — Official Website

The official corporate website for **Airsol HVAC** ([airsolhvac.com](https://airsolhvac.com/)), showcasing commercial and industrial HVAC solutions, air conditioning systems, ventilation, kitchen exhaust systems, and thermal/acoustic insulation products.

## 🌐 Live Website
**[https://airsolhvac.com/](https://airsolhvac.com/)**

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Frameworks & Libraries:** Bootstrap, Owl Carousel, Themify Icons
* **Server Configuration:** Apache (`.htaccess`)

```text
Airsol-HVAC-Web/
